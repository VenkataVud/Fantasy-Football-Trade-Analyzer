# Fantasy Football Trade Analyzer

## Project Goal

This project is a Java program that helps fantasy football players evaluate trades. Users can compare players using their season statistics to determine which side of a trade has more value.

## MVP Scope

The program will load NFL player statistics from a CSV file. Users will enter players on both sides of a trade, and the program will calculate their fantasy values and recommend which side is better.

## Tech Stack

The project will use Java, Scanner for user input, BufferedReader for reading CSV files, and ArrayList for storing player data. I will use VS Code to write the code and GitHub to track progress. Player statistics will come from the nflverse dataset.

## Future Plans

In the future, I would like to add automatic stat updates, recent player performance analysis, and different fantasy scoring formats. I may also create an HTML/CSS interface to make the program easier to use.
